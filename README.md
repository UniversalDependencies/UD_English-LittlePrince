# Summary
This treebank contains manually corrected Universal Dependency annotations for the English translation of *The Little Prince*. The initial parse was automatically generated by Georgetown's system and then manually corrected using ArboratorGrew for easy editing.

# Introduction
This treebank is based on the English translation of *The Little Prince* and consists of **500 sentences** (validated manually). The project was undertaken by students in the 11-422 Grammar Formalisms course at Carnegie Mellon University, taught by Prof. Lori Levin, with the aim of practicing dependency parsing and analyzing linguistic structures. We used Georgetown’s automated parser as a base, which was then manually edited by two annotators per sentence, with approximately 25% of the sentences checked by the course coordinator. The annotations follow the Universal Dependencies guidelines and have been validated for correctness and consistency.
